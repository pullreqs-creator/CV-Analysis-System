# AI-Powered Skill Gap Analyst

## 1. Objective & Architecture

This project implements a multi-agent system designed to act as an intelligent assistant for a technical recruiter. It analyzes a candidate's CV against current market demands for a specific role (e.g., "Senior AI Engineer") to produce a detailed skill-gap analysis, identify key strengths, and propose a personalized upskilling plan. The system goes beyond simple keyword matching by using a sequence of specialized AI agents to perform a deep, contextual analysis.

### Architectural Overview

The system is built using Python with the LangGraph framework to orchestrate a workflow of five distinct agents. Each agent has a single responsibility, passing its output to the next agent in the chain to build a comprehensive final report.

**Agent Workflow:**

[Start] -> [CV Parser] -> [Skill Analyst] -> [Market Analyst] -> [Gap Analyzer] -> [Report Formatter] -> [End]

* **1. CV Parsing & Normalization Agent:** Ingests the raw CV text and parses it into a structured JSON format, extracting key sections like experience, skills, and education.
* **2. Specialized Skill Analyst Agent:** Analyzes the structured CV data to identify both explicit and implicit skills (e.g., inferring knowledge of LLMs from a project that used LangChain).
* **3. Market Intelligence Agent:** Uses the external JSearch API to query real-time job listings for the target role and summarize the most in-demand skills and technologies.
* **4. Gap Analysis Agent:** The core reasoning agent. It takes the candidate's skill profile and the market demand summary, compares them, and generates a structured JSON object containing the skill-gap analysis, key strengths, and an upskilling plan.
* **5. Report Formatting Agent:** Takes the structured output from all previous agents and assembles it into a final, well-structured, and human-readable report in Markdown format.

## 2. Environment Setup

Follow these steps to set up and run the project locally.

### Step 1: Clone the Repository

```bash
git clone <your-repo-url>
cd AI-Powered-Skill-Gap-Analyst
```

### Step 2: Create and Activate a Virtual Environment

```bash
# For macOS/Linux
python3 -m venv venv
source venv/bin/activate

# For Windows
python -m venv venv
venv\Scripts\activate
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Set Up API Keys
You will need two API keys for this project. Create a file named .env in the root of the project directory and add your keys:
```bash
# Get this from Google Al Studio or Google Cloud Console
GOOGLE_API_KEY="your-google-api-key-here"

# Get this from RapidAPI by subscribing to the JSearch API
JSEARCH_API_KEY="your-jsearch-api-key-here"
```
* Google AI Studio: https://aistudio.google.com/app/apikey

* JSearch on RapidAPI: https://rapidapi.com/jsearch/api/jsearch

(Note: If you are using the Vertex AI library, you do not need the GOOGLE_API_KEY in the .env file. Instead, authenticate by running gcloud auth application-default login in your terminal.)

---

## 3. How to Run the Application

Ensure you have a sample_cv.txt file in the root directory. Then, run the main script:
```bash
python main.py
```
The application will execute the agent workflow and print the final report to the console. It will also save the output to a file named final_report.md in the project directory.
