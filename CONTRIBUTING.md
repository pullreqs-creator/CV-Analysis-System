# Contributing to CV-Analysis-System

Thank you for your interest in contributing to CV-Analysis-System! Contributions are welcome and appreciated. Please read these guidelines before getting started.

---

## How Can I Contribute?

### 1. Reporting Bugs

- Please open an [issue](https://github.com/ZidanMau24/CV-Analysis-System/issues) and include:
  - A clear, descriptive title.
  - Steps to reproduce the bug.
  - Expected and actual behavior.
  - Screenshots or code snippets if applicable.

### 2. Suggesting Enhancements

- Open an issue with the `[enhancement]` label.
- Describe your idea, its use case, and why it would be beneficial to the project.

### 3. Pull Requests

- Fork the repository and create your branch from `main`.
- Install all dependencies and make sure your code runs locally.
- Add tests for new features or bug fixes whenever possible.
- Follow the existing code style and conventions.
- Document your code and update the README if necessary.
- Make sure your changes do not introduce new bugs.
- Submit your pull request with a clear description of what you changed and why.

---

## Development Setup

1. Clone your fork:
    ```bash
    git clone https://github.com/YOUR-USERNAME/CV-Analysis-System.git
    cd CV-Analysis-System
    ```
2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3. Set up your `.env` file as described in the README.
4. Run the tests:
    ```bash
    pytest
    ```
